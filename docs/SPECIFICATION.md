## 1. ОБЩЕЕ ОПИСАНИЕ ПРИЛОЖЕНИЯ

### 1.1 Назначение

ECommerce App - мобильное приложение электронной коммерции для платформы Android, предназначенное для организации онлайн-продаж товаров. Приложение предоставляет полный цикл взаимодействия между покупателями и администраторами магазина.

### 1.2 Ключевые возможности

**Для покупателей (Customer):**

- Просмотр каталога товаров с фильтрацией по категориям
- Добавление товаров в корзину с сохранением локально
- Оформление заказов с выбором адреса на карте (Yandex Maps)
- Просмотр истории заказов
- Создание отзывов с фотографиями
- Сохранение адресов доставки

**Для администраторов (Admin):**

- Управление товарами (CRUD-операции)
- Управление категориями товаров
- Управление заказами и изменение статусов
- Модерация отзывов пользователей
- Аналитика продаж с визуализацией графиков
- Экспорт данных в CSV/Excel форматы
- Генерация PDF-отчетов

### 1.3 Основные преимущества мобильного решения

1. **Доступность** - покупки в любом месте и в любое время
2. **Геолокация** - автоматическое определение местоположения для доставки
3. **Push-уведомления** - возможность информирования о статусе заказа (расширение)
4. **Оффлайн-функциональность** - корзина сохраняется локально
5. **Удобный UX** - оптимизированный интерфейс под мобильные устройства

## 3. СИСТЕМНЫЕ ТРЕБОВАНИЯ

### 3.1 Целевые устройства

**Тип устройств:** Смартфоны Android

**Обоснование:**

- Основная аудитория использует смартфоны для онлайн-покупок
- Необходима геолокация для выбора адреса доставки
- Компактный интерфейс оптимален для быстрых покупок

### 3.2 Требования к устройству


| Параметр              | Минимальное значение | Рекомендуемое |
| ----------------------------- | --------------------------------------- | -------------------------- |
| Android версия          | 8.0 (API 26)                            | 13.0+ (API 33+)            |
| Target SDK                    | 36                                      | 36                         |
| Compile SDK                   | 36                                      | 36                         |
| ОЗУ                        | 2 GB                                    | 4+ GB                      |

### 3.3 Разрешения приложения

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"
    android:maxSdkVersion="28" />
```

**Описание разрешений:**

- `INTERNET` - подключение к серверу API
- `ACCESS_FINE_LOCATION` - точное определение координат для карты
- `ACCESS_COARSE_LOCATION` - примерное местоположение
- `WRITE_EXTERNAL_STORAGE` - сохранение PDF/Excel файлов (Android 9 и ниже)

### 3.4 Аппаратные требования

- **Процессор:** ARM64 или x86_64
- **Экран:** от 5 дюймов, разрешение от 720x1280
- **Сенсор:** Touchscreen с multi-touch
- **Датчики:** GPS (опционально)
- **Камера:** Не требуется (загрузка фото из галереи)

## 4. АРХИТЕКТУРА ПРИЛОЖЕНИЯ

### 4.1 Архитектурный паттерн

Приложение построено на архитектуре **MVVM + Clean Architecture** с четким разделением на слои:

```
┌─────────────────────────────────────────────┐
│              UI Layer (Compose)             │
│    Screens, Components, ViewModels          │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│            Domain Layer                      │
│    Repositories (Abstraction)                │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│             Data Layer                       │
│   Remote (Retrofit) + Local (Room/DataStore) │
└─────────────────────────────────────────────┘
```

### 4.3 Dependency Injection (Hilt)

Все зависимости инжектируются через Hilt:

```kotlin
@Module
@InstallIn(SingletonComponent::class)
object AppModule {
    @Provides @Singleton
    fun provideApiService(retrofit: Retrofit): ApiService

    @Provides @Singleton
    fun provideAppDatabase(context: Context): AppDatabase

    @Provides @Singleton
    fun provideUserPreferences(context: Context): UserPreferences
}
```

### 4.4 Управление состоянием

**StateFlow + Compose State:**

```kotlin
@HiltViewModel
class SomeViewModel @Inject constructor(
    private val repository: SomeRepository
) : ViewModel() {
    private val _state = MutableStateFlow(SomeState())
    val state = _state.asStateFlow()

    fun updateState() {
        _state.update { it.copy(isLoading = true) }
    }
}
```

**Resource Wrapper:**

```kotlin
sealed class Resource<T>(val data: T? = null, val message: String? = null) {
    class Success<T>(data: T) : Resource<T>(data)
    class Error<T>(message: String, data: T? = null) : Resource<T>(data, message)
    class Loading<T>(data: T? = null) : Resource<T>(data)
}
```

## 6. ОПИСАНИЕ ЭКРАНОВ И ФУНКЦИОНАЛЬНОСТИ

### 6.1 Экраны аутентификации

#### LoginScreen (Вход)

- Поля: логин, пароль
- Кнопка входа
- Ссылка на регистрацию
- Автоматическое перенаправление по роли (admin → Dashboard, user → Home)

#### RegisterScreen (Регистрация)

- Поля: имя пользователя, email, пароль
- Выбор роли (user/admin)
- Кнопка регистрации
- Возврат на экран входа после успешной регистрации

### 6.2 Экраны покупателя (Customer)

#### HomeScreen (Главная)

**UI элементы:**

- TopAppBar: заголовок "Магазин", иконка корзины (с badge), профиль
- Горизонтальный список фильтров по категориям (LazyRow)
- Список товаров (LazyColumn) с карточками

**Функциональность:**

- Просмотр всех товаров
- Фильтрация по категориям
- Просмотр количества товаров в корзине
- Переход к деталям товара, корзине, профилю

#### ProductDetailScreen (Детали товара)

**UI элементы:**

- Галерея изображений (LazyRow с возможностью zoom)
- Название и цена товара
- Рейтинг и количество отзывов
- Статус наличия
- Описание товара
- Список отзывов пользователей
- BottomBar: управление количеством, кнопка "В корзину"

**Функциональность:**

- Просмотр полной информации о товаре
- Увеличение изображений
- Выбор количества (от 1 до наличия на складе)
- Добавление в корзину

#### CartScreen (Корзина)

**UI элементы:**

- Список товаров в корзине
- Для каждого товара: изображение, название, цена, управление количеством, кнопка удаления
- BottomBar: итоговая сумма, кнопка "Оформить заказ"

**Функциональность:**

- Изменение количества товаров
- Удаление товаров
- Расчет общей суммы
- Переход к оформлению

#### CheckoutScreen (Оформление заказа)

**UI элементы:**

- Поля контактной информации (имя, телефон, адрес)
- Кнопка выбора адреса на карте
- Отображение координат (если выбраны)
- Чекбоксы: сохранить адрес, использовать по умолчанию
- Способ оплаты (карта/наличные)
- Список товаров заказа
- BottomBar: итого, кнопка "Оформить заказ"

**Функциональность:**

- Ввод контактных данных
- Выбор сохраненного адреса или ввод нового
- Выбор адреса на карте Yandex Maps
- Сохранение адреса для будущих заказов
- Создание заказа и очистка корзины

#### MapAddressPickerScreen (Выбор адреса на карте)

**UI элементы:**

- Yandex MapView на весь экран
- Кнопка "Моё местоположение"

**Функциональность:**

- Получение текущего местоположения
- Возврат выбранного адреса на предыдущий экран

#### OrdersScreen (Мои заказы)

**UI элементы:**

- Список заказов с карточками

**Статусы заказов:**

- Ожидает (Secondary color)
- Обрабатывается (Tertiary color)
- Завершен (Primary color)
- Отменен (Error color)

**Функциональность:**

- Просмотр истории заказов
- Переход к деталям заказа

#### OrderDetailScreen (Детали заказа)

**UI элементы:**

- Статус заказа
- Даты создания и обновления
- Информация о доставке (имя, телефон, адрес, способ оплаты)
- Список товаров с возможностью оценки (для завершенных заказов)
- Итоговая сумма
- Кнопка удаления заказа

**Функциональность:**

- Просмотр полной информации о заказе
- Удаление заказа
- Создание/редактирование/удаление отзывов на товары

**UI элементы:**

- Кнопка выхода

**Функциональность:**

- Просмотр информации о пользователе
- Навигация к разделам
- Выход из аккаунта

**UI элементы:**

- Список сохраненных адресов доставки

## 11. ИНСТРУКЦИЯ ПОЛЬЗОВАТЕЛЯ

### 11.1 Установка и первый запуск

1. **Установка:** Загрузите APK или установите из Google Play
2. **Разрешения:** При первом запуске предоставьте разрешения на геолокацию (для карты)
3. **Регистрация:** Создайте аккаунт с указанием email и пароля
4. **Вход:** Используйте логин и пароль для входа

### 11.2 Работа с каталогом товаров

1. **Просмотр товаров:** На главном экране отображаются все товары
2. **Фильтрация:** Используйте горизонтальные кнопки категорий для фильтрации
3. **Детали товара:** Нажмите на карточку товара для просмотра подробностей
4. **Изображения:** Нажмите на изображение для увеличения

### 11.3 Работа с корзиной

1. **Добавление:** На странице товара выберите количество и нажмите "В корзину"
2. **Просмотр корзины:** Нажмите на иконку корзины в правом верхнем углу
3. **Изменение количества:** Используйте кнопки +/- для изменения
4. **Удаление:** Нажмите на красную иконку удаления

### 11.4 Оформление заказа

1. **Переход:** Нажмите "Оформить заказ" в корзине
2. **Контакты:** Заполните имя и телефон
3. **Адрес:** Введите адрес вручную или нажмите иконку карты
4. **Карта:** На карте нажмите на нужную точку и подтвердите выбор
5. **Сохранение:** Установите флажок, если хотите сохранить адрес
6. **Оплата:** Выберите способ оплаты (карта или наличные)
7. **Подтверждение:** Нажмите "Оформить заказ"

### 11.5 История заказов и отзывы

1. **Просмотр заказов:** Профиль → Мои заказы
2. **Детали заказа:** Нажмите на заказ для просмотра
3. **Создание отзыва:** Для завершенных заказов доступна кнопка "Оценить товар"
4. **Редактирование:** Свой отзыв можно изменить или удалить

### 11.6 Управление профилем

1. **Настройки:** Профиль → Настройки
2. **Адреса:** Добавляйте, редактируйте и удаляйте адреса доставки
3. **По умолчанию:** Установите флажок для основного адреса
4. **Выход:** Профиль → Выйти

### 11.7 Инструкция для администратора

#### Управление товарами

1. Dashboard → Товары
2. Для добавления нажмите "Добавить товар"
3. Заполните форму и нажмите "Создать"
4. Для редактирования нажмите на товар
5. Загружайте изображения через кнопку "Добавить"

#### Управление заказами

1. Dashboard → Заказы
2. Используйте поиск и фильтры для поиска
3. Нажмите на заказ для просмотра деталей
4. Измените статус через кнопку в шапке

#### Аналитика

1. Dashboard → Аналитика
2. Переключайтесь между вкладками
3. Настройте фильтры периодов
4. Для создания отчета нажмите "Создать PDF отчет"

#### Экспорт данных

1. Dashboard → Экспорт (или через аналитику)
2. Выберите тип данных и формат
3. Нажмите "Скачать"
4. Файл сохранится в папку Downloads

### 12.5 Пути сокращения последовательности действий

#### Для покупки товара (20 → 15 шагов):

1. **Автовход:** Сохранение сессии исключает шаги 2-3 (-2 шага)
2. **Быстрая покупка:** Добавить кнопку "Купить сейчас" на карточке товара (-3 шага)
3. **Автозаполнение:** Использование сохраненного адреса (-4 шага)

#### Для добавления отзыва (9 → 6 шагов):

1. **Push-уведомление:** Переход к отзыву из уведомления о доставке (-3 шага)
2. **Экспресс-отзыв:** Только рейтинг без комментария (-2 шага)

#### Для добавления товара (14 → 10 шагов):

1. **Шаблоны товаров:** Автозаполнение из шаблона (-3 шага)
2. **Импорт из Excel:** Массовая загрузка товаров (-10+ шагов для нескольких товаров)

#### Для обработки заказа (10 → 6 шагов):

1. **Быстрые действия:** Кнопки статусов в списке заказов (-4 шага)
2. **Автоматические статусы:** Интеграция с доставкой (-все шаги)
